# Research Autopilot

Founded by Yunbo Long in October 2026.

Explore the [public navigation demo](https://yunbo-max.github.io/research-autopilot/): three illustrative research journeys across sixteen regions, including experiments, writing, peer review, release and communication.

The examples use authored routes and sample observations. They do not run experiments or read private projects. This repository contains the website and public demo; the research skills and internal workflow materials are not included in the current version.
