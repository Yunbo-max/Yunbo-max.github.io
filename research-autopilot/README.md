# Research Autopilot

Founded by Yunbo Long in October 2026.

Explore the [research module atlas](https://yunbo-max.github.io/research-autopilot/): 84 research tasks across 16 modules, with 221 connections from the current node registry.

Each illustrated continent represents a module. The globe can rotate, pause and select modules or tasks; a complete HTML directory is also available. The public atlas describes the workflow and does not execute experiments or read private projects. Skill instructions, executable gates and project records remain outside this website repository.

The public directory is generated by `scripts/build-research-atlas.py --registry /path/to/research-nodes.json`. It exports module descriptions, task labels and connection topology, verifies the 16/84/221 inventory, and records the input registry's SHA-256. The continent positions are illustrative and do not determine execution order.
