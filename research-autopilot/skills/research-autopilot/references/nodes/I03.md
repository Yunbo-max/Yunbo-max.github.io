# I03 会场、期刊与投稿阶段

这是 research-autopilot 的内部节点 skill 入口。

## 状态与任务契约

- 内容状态：自有规范详细覆盖。
- 输入：贡献类型、截止时间
- 输出：会场规则包
- 验收：按 venue/year/track/article_type/stage 核对官方规则；支持 AI 顶会、期刊与 Nature 模式。
- 版本：1.1.0

## 使用自有规范

1. 核对实际材料、版本、当前决策与已授权范围，延续已有研究。
2. 用 `python3 scripts/research_nodes.py show I03` 逐段核验并加载以下原文。来源变化先核对，保留旧版本。
3. 按输入、输出和验收交付；操作规范、实际回执与科学证据分别记录。

## 实际能力与验证

绑定校验只证明规范可定位。实际运行、任务验收、外部操作和科研主张须分别保存证据。尚未连接的项目调度器、GPU 或账号服务不能登记为已实现。

## 小点之间的交接

按真实任务选择边的条件。E 区执行/修复返回实际调用节点及任务身份；84 点和 221 边不新增合法状态机 route/phase/gate。

| 到节点 | 关系 | 条件 | 交付内容 |
|---|---|---|---|
| W01 | 输入 | 会场或阶段已明确 | venue、year、track、article type 和 stage |
| R01 | 输入 | 准备提交时核对当次规则 | 匿名、页数、材料和日期约束 |
| A03 | 输入 | 准备预印本时核对公开条件 | 当前投稿阶段和公开规则 |
