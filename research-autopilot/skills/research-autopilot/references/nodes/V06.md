# V06 统计审计与证据冻结

这是 research-autopilot 的内部节点 skill 入口。

## 状态与任务契约

- 内容状态：自有规范详细覆盖。
- 输入：全部结果、协议和文献
- 输出：支持、收窄、撤回的主张
- 验收：多重比较、方差和独立性适用时处理；冻结不覆盖旧版本。
- 版本：1.1.0

## 使用自有规范

1. 核对实际材料、版本、当前决策与已授权范围，延续已有研究。
2. 用 `python3 scripts/research_nodes.py show V06` 逐段核验并加载以下原文。来源变化先核对，保留旧版本。
3. 按输入、输出和验收交付；操作规范、实际回执与科学证据分别记录。

## 实际能力与验证

绑定校验只证明规范可定位。实际运行、任务验收、外部操作和科研主张须分别保存证据。尚未连接的项目调度器、GPU 或账号服务不能登记为已实现。

## 小点之间的交接

按真实任务选择边的条件。E 区执行/修复返回实际调用节点及任务身份；84 点和 221 边不新增合法状态机 route/phase/gate。

| 到节点 | 关系 | 条件 | 交付内容 |
|---|---|---|---|
| W02 | 分支 | 所有适用证据义务充分且有效 | 支持、收窄或撤回后的主张快照 |
| W09 | 失效 | 已有稿件或公开材料依赖了变化的结果 | 新证据版本与受影响主张 |
| F02 | 输入 | 需要绘制或更新可信结果图表 | 精确数据、分母和不确定性 |
| A04 | 输入 | 准备或更新发布版本 | 经过审计的证据与范围 |
| V01 | 修订 | 某项必要证据义务仍不满足 | 明确的缺口；只安排必要补充 |
| H03 | 修订 | 证据否定或收窄现有主张 | 需要撤回或重定义的子主张 |
| E04 | 修订 | 证据有效性审计发现故障 | 受影响运行和根因线索 |
| R04 | 输入 | 回应依赖新实验或统计审计 | 经验收的补充证据 |
