# W09 新结果的依赖传播

这是 research-autopilot 的内部节点 skill 入口。

## 状态与任务契约

- 内容状态：自有规范详细覆盖。
- 输入：结果、claim 或文献变化
- 输出：受影响段落、图表和宣传清单
- 验收：只重写相关依赖；临时 draft 可以存在，提交版不能使用失效结论。
- 版本：1.1.0

## 使用自有规范

1. 核对实际材料、版本、当前决策与已授权范围，延续已有研究。
2. 用 `python3 scripts/research_nodes.py show W09` 逐段核验并加载以下原文。来源变化先核对，保留旧版本。
3. 按输入、输出和验收交付；操作规范、实际回执与科学证据分别记录。

按当前段落、section 或整稿范围读取写作规范；整稿一致性任务调用完整 writing-top-tier-papers。

## 实际能力与验证

绑定校验只证明规范可定位。实际运行、任务验收、外部操作和科研主张须分别保存证据。尚未连接的项目调度器、GPU 或账号服务不能登记为已实现。

## 小点之间的交接

按真实任务选择边的条件。E 区执行/修复返回实际调用节点及任务身份；84 点和 221 边不新增合法状态机 route/phase/gate。

| 到节点 | 关系 | 条件 | 交付内容 |
|---|---|---|---|
| W02 | 修订 | 变化影响中心主张或必要性 | 受影响主张与新证据范围 |
| W03 | 修订 | 变化改变关键证据的重要性 | 需要调整 main 或 appendix 的内容 |
| W04 | 修订 | 变化影响 section 或段落职责 | 受影响 section 和 paragraph 实例 |
| W06 | 修订 | 变化只影响定位、动机或引用 | 具体段落和证据定位 |
| W07 | 修订 | 变化影响方法、数字或解释 | 具体段落、结果与限制 |
| W08 | 修订 | 变化影响摘要、题目或结论 | 与新证据一致的 framing |
| F01 | 失效 | 变化影响机制或动机图 | 相关图形中的失效语义 |
