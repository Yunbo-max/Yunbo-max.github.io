# V01 主张到实验矩阵

这是 research-autopilot 的内部节点 skill 入口。

## 状态与任务契约

- 内容状态：自有规范详细覆盖。
- 输入：Gate A 或成熟结果
- 输出：完整证据义务与扩展协议
- 验收：按尚未支持的主张扩展，不自动堆模型和数据集。
- 版本：1.1.0

## 使用自有规范

1. 核对实际材料、版本、当前决策与已授权范围，延续已有研究。
2. 用 `python3 scripts/research_nodes.py show V01` 逐段核验并加载以下原文。来源变化先核对，保留旧版本。
3. 按输入、输出和验收交付；操作规范、实际回执与科学证据分别记录。

## 实际能力与验证

绑定校验只证明规范可定位。实际运行、任务验收、外部操作和科研主张须分别保存证据。尚未连接的项目调度器、GPU 或账号服务不能登记为已实现。

## 小点之间的交接

按真实任务选择边的条件。E 区执行/修复返回实际调用节点及任务身份；84 点和 221 边不新增合法状态机 route/phase/gate。

| 到节点 | 关系 | 条件 | 交付内容 |
|---|---|---|---|
| V02 | 输入 | 矩阵要求强基线或重复验证 | 该项冻结实验协议和验收义务 |
| V03 | 输入 | 主张包含需要实证的机制解释 | 该机制的对照与替换义务 |
| V04 | 输入 | 主张包含泛化或鲁棒性范围 | 所需外部任务与边界验证 |
| V05 | 输入 | 主张涉及效率、质量或失败后果 | 统一口径和分析义务 |
| V06 | 输入 | 审计按矩阵检查所有适用义务 | 哪些必须完成、哪些不适用及其理由 |
