# B05 Natural Gate 0

这是 research-autopilot 的内部节点 skill 入口。

## 状态与任务契约

- 内容状态：自有规范详细覆盖。
- 输入：问题卡与自然失败证据
- 输出：PASS/KILL/INCONCLUSIVE
- 验收：PASS 依赖重要后果和简单方案剩余缺口；未知不能算 PASS。
- 版本：1.1.0

## 使用自有规范

1. 核对实际材料、版本、当前决策与已授权范围，延续已有研究。
2. 用 `python3 scripts/research_nodes.py show B05` 逐段核验并加载以下原文。来源变化先核对，保留旧版本。
3. 按输入、输出和验收交付；操作规范、实际回执与科学证据分别记录。

## 实际能力与验证

绑定校验只证明规范可定位。实际运行、任务验收、外部操作和科研主张须分别保存证据。尚未连接的项目调度器、GPU 或账号服务不能登记为已实现。

## 小点之间的交接

按真实任务选择边的条件。E 区执行/修复返回实际调用节点及任务身份；84 点和 221 边不新增合法状态机 route/phase/gate。

| 到节点 | 关系 | 条件 | 交付内容 |
|---|---|---|---|
| H01 | 分支 | Natural Gate 0 为 PASS | 真实问题卡和简单方案剩余缺口 |
| B02 | 修订 | INCONCLUSIVE 且缺自然失败证据 | 需要补的分母、频率或后果 |
| B03 | 修订 | INCONCLUSIVE 且简单方案尚未合格 | 基线资格的具体缺口 |
| I04 | 分支 | KILL 或简单方案已足够 | 简化、暂停或结束当前贡献的记录 |
