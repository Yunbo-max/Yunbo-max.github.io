# I01 入口与当前决策

这是 research-autopilot 的内部节点 skill 入口。

## 状态与任务契约

- 内容状态：自有规范详细覆盖。
- 输入：真实可用资产
- 输出：I/M/R 起点与当前路线
- 验收：未知保持未知；成熟结果先审计，不重做全部前期流程。
- 版本：1.1.0

## 使用自有规范

1. 核对实际材料、版本、当前决策与已授权范围，延续已有研究。
2. 用 `python3 scripts/research_nodes.py show I01` 逐段核验并加载以下原文。来源变化先核对，保留旧版本。
3. 按输入、输出和验收交付；操作规范、实际回执与科学证据分别记录。

## 实际能力与验证

绑定校验只证明规范可定位。实际运行、任务验收、外部操作和科研主张须分别保存证据。尚未连接的项目调度器、GPU 或账号服务不能登记为已实现。

## 小点之间的交接

按真实任务选择边的条件。E 区执行/修复返回实际调用节点及任务身份；84 点和 221 边不新增合法状态机 route/phase/gate。

| 到节点 | 关系 | 条件 | 交付内容 |
|---|---|---|---|
| I02 | 输入 | 需要确定贡献类型 | 当前决策和可信资产 |
| L01 | 分支 | 只有方向或文献不足 | 待定位的问题与检索线索 |
| B01 | 分支 | 需要核对任务和自然失败 | 真实任务、评价器与已有材料 |
| H02 | 分支 | 已有方法但必要性尚未核对 | 方法、已有结果和问题缺口 |
| V06 | 分支 | 已有较完整实验，先审计有效性 | 原始结果、配置及现有主张 |
| W02 | 分支 | 现有证据已通过审计且当前决定是写作 | 有效证据快照 |
| R02 | 分支 | 已有审稿意见或拒稿材料 | 评审原文和当前稿件 |
| A04 | 分支 | 当前决定是准备公开成果 | 已核对的稿件和资产版本 |
