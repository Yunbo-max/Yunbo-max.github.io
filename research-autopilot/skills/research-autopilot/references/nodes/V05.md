# V05 质量、成本与失败分析

这是 research-autopilot 的内部节点 skill 入口。

## 状态与任务契约

- 内容状态：自有规范详细覆盖。
- 输入：全部 run 与错误案例
- 输出：质量成本曲线与局限
- 验收：端点指标和真实代价共同判断；未解释的不利结果留在核心解释中。
- 版本：1.1.0

## 使用自有规范

1. 核对实际材料、版本、当前决策与已授权范围，延续已有研究。
2. 用 `python3 scripts/research_nodes.py show V05` 逐段核验并加载以下原文。来源变化先核对，保留旧版本。
3. 按输入、输出和验收交付；操作规范、实际回执与科学证据分别记录。
