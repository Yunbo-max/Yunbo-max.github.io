# B03 强简单基线资格

这是 research-autopilot 的内部节点 skill 入口。

## 状态与任务契约

- 内容状态：自有规范详细覆盖。
- 输入：prompt、文本、检索、checker 或 solver
- 输出：公平调优与基线报告
- 验收：输入信息、调用量和资源匹配；latent memory 必须对比合理文本方案。
- 版本：1.1.0

## 使用自有规范

1. 核对实际材料、版本、当前决策与已授权范围，延续已有研究。
2. 用 `python3 scripts/research_nodes.py show B03` 逐段核验并加载以下原文。来源变化先核对，保留旧版本。
3. 按输入、输出和验收交付；操作规范、实际回执与科学证据分别记录。

绑定校验只证明规范可定位。实际运行、任务验收、外部操作和科研主张须分别保存证据。尚未连接的项目调度器、GPU 或账号服务不能登记为已实现。
