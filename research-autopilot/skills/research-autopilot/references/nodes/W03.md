# W03 Main 与 Appendix 分配

这是 research-autopilot 的内部节点 skill 入口。

## 状态与任务契约

- 内容状态：自有规范详细覆盖。
- 输入：主张证据矩阵和篇幅
- 输出：内容位置及理由
- 验收：决定主张解释的证据留 main；appendix 承担深度与复现。
- 版本：1.1.0

## 使用自有规范

1. 核对实际材料、版本、当前决策与已授权范围，延续已有研究。
2. 用 `python3 scripts/research_nodes.py show W03` 逐段核验并加载以下原文。来源变化先核对，保留旧版本。
3. 按输入、输出和验收交付；操作规范、实际回执与科学证据分别记录。

按当前段落、section 或整稿范围读取写作规范；整稿一致性任务调用完整 writing-top-tier-papers。
