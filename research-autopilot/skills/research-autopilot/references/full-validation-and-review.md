# Claim-driven validation, submission and review

These contracts augment gate-a.md and execution-and-handoffs.md. Read current
official venue instructions. Leading-conference rigor is evidence closure and
honest scope, not a fixed number of experiments/seeds or a promised acceptance.

## V01 Claim-to-experiment matrix

For each central claim record its type, target population, strongest anti-claim,
minimum evidence, comparator/control, split/unit, metric/uncertainty, protocol,
cost, run order, result locator, supported scope and unresolved obligation.
Prioritize decision-changing evidence before showcase experiments. Reuse valid
existing evidence with an explicitly retrospective audit; don't relabel it
prospective. New experiments close named obligations rather than fill a checklist.

## V02 Baselines and repeats

Include strongest relevant published and simple/training-free alternatives with
qualified implementations and fair tuning/information/compute. Explain exclusions.
Select repetitions and sample size for the estimand, variance/precision and budget;
three seeds is not a universal law. Identify independent unit, paired structure,
training/decoding randomness, all runs and uncertainty calculation. An aggregate
without a denominator or qualified scorer does not close a claim.

## V03 Mechanism, ablation and replacement

Test each component's responsibility, competing causal explanation and simpler
replacement. Adding parameters/search/information can explain an apparent gain.
An A vs A+B ablation does not identify B alone or an A×B interaction. Use the
appropriate factorial/substitution controls when claiming complementarity. Keep
negative/null controls and failure cases visible. Observed association is not
automatically a causal mechanism.

## V04 Generalization and boundaries

Choose model/data/task/scale/time/condition axes tied to scope claims; don't require
an arbitrary full Cartesian product. Use genuinely independent conditions and
freeze choices before confirmation. Inspect worst groups, drift, long tails and
failure regimes when material. Record unknown boundaries and narrow wording to
tested conditions. New broad claims need additional evidence.

## V05 Quality, cost and failures

Measure actual task endpoint alongside latency/memory/tokens/API/energy or training
cost when claimed. State warmup, batching, hardware, cache and throughput vs latency.
Analyze naturally sampled failures with denominator, consequence and competing
causes. Distinguish measurement error, implementation invalidity and valid adverse
evidence. Central unfavorable evidence belongs in the main explanation, even if
details go in the appendix. All failed exploration contributes to total resources.

## V06 Statistical audit and evidence freeze

Check selection bias, dependence, missing/unscored samples, multiple comparisons,
uncertainty source and appropriate analysis. No blanket p-value or n threshold.
Audit raw-to-table calculations and claims before freezing evidence identity.
Every claim receives supported/partial/unsupported/contradicted plus scope, locator,
uncertainty and next action. Freeze the complete package; retain negative/unselected
runs. NeurIPS checklist is a current reporting reference: scope, limitations,
assumptions/proofs, reproducibility, tuning, uncertainty and per-run/total compute.
It is not a publication guarantee. Feed W with allowed and forbidden statements.

## R01 Submission package

Resolve current venue/year/track/stage rules from official sources. Check page
limits/template/anonymity, abstract/author list/conflicts, data/code attachments,
ethics/disclosures and PDF consistency only as applicable. Produce a reviewable
package with version/digest and a submission checklist. Actual upload/final submit
uses the named account and authorization; record real portal submission ID,
timestamp/status/version. A prepared PDF is not a submission receipt.

## R02 Independent review and issue ledger

When multi-agent/model review is requested or appropriate, give independent
reviewers the same manuscript/evidence snapshot and no prior consensus. Assign
scientific claims, math, evaluation, implementation and presentation scopes; retain
all reports and dissent. Model diversity alone does not prove independence.
Each issue needs manuscript/evidence locator, factual premise, consequence,
confidence and feasible remedy. Distinguish unreported from unperformed.
Human subject experts adjudicate material technical disagreements; AI reviewers
can request checks but cannot validate experiments by voting. No compulsory
review-until-high-score loop. Review scope/budget and actual model identities are
recorded; unavailable reviewers remain unavailable.

## R03 Rebuttal priorities

Map reviewer IDs and every issue to factual correction, explanation, missing
evidence, method defect, novelty collision or scope preference. Inspect the
premise before agreeing. Rank by likely decision impact, existing evidence,
discussion window and authorized resources. Draft concrete answers first; run
only informative, feasible supplement experiments with real scope. Preserve
original submission evidence and label post-review results/version separately.

## R04 Response and revision

For each issue answer directly, give verified evidence/locator, clarify uncertainty,
and state exact manuscript change if made. Never claim a planned experiment was
performed. Maintain issue → response → evidence → change-location mapping and
respect current response format/limits/anonymity. A shared editor reconciles
conflicting model drafts against evidence; a human confirms author-only facts.
Keep response, manuscript, tables and released code consistent.

## R05 Decision, retargeting and final version

Record actual decision and grounds. Accept, retarget, repair, pause or stop according
to evidence and human goal. A template-only retarget does not restart trustworthy
experiments; a changed central claim/problem reopens affected obligations. For
camera-ready verify author/venue/copyright/disclosure rules and final cross-asset
version links. Archive the submitted and accepted snapshots independently.
